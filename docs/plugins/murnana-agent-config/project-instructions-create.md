# project-instructions-create スキル

`/murnana-agent-config:project-instructions-create` — claude.ai の Project の「指示」（Instructions）欄に貼り付ける文章を、ヒアリングを通して作成・見直しする。Claude Code 用のルールではなく、claude.ai の Project 向け。

## 使い方

- 起動は**明示的なスラッシュコマンドのみ**（`disable-model-invocation: true`）。
- `$ARGUMENTS` に、プロジェクトの目的、または見直したい既存の指示（またはそのパス）を渡せる。
- 質問・問題点の指摘はユーザーが書いている言語で行い、生成される指示の本文は**常に英語**。
- 生成される指示には必ず `Language` 節が入る。既定は「会話でユーザーが書いている言語で応答・質問する」。
- 対象が Claude Code だと分かった場合は、`rule-create` や CLAUDE.md を案内して終了する。

| Step | やること |
|---|---|
| 1 | 会話・ファイル・既存の指示を確認する。見直しモードでは、ヒアリング前に問題点（曖昧・矛盾・重複・Language 節の欠落）と修正案を一覧にする |
| 2 | 3ラウンド・12問でヒアリングする（必須4問 → 重要4問 → 任意4問）。各ラウンドは `AskUserQuestion` 1回（最大4問） |
| 3 | テンプレートに沿って英語の指示を下書きする |
| 4 | セルフチェック（Language 節、原則の遵守、矛盾、プロジェクトファイルとの重複） |
| 5 | コードブロックで提示する。見直しモードでは変更サマリー、補った既定値、確認質問（最大3問）、テスト用プロンプト2〜3個も添える |

## 設計メモ

- **質問を12個に絞った**: 以前は15個だった。「トーン」と「出力形式」、「避けたいこと」と「繰り返し受ける修正」のように重なる項目を統合し、各ラウンドが4問以内に収まるようにした。
- **言語ルールを一本化した**: 言語に関する記述が冒頭・ヒアリング・テンプレート・セルフチェックに散らばっていたので、`Language` 節に集約した。
- **見直しモードの出力を定義した**: 既存の指示がある場合は、先に問題点を示してから、足りない部分だけを聞く。
- **Gotchas**: 指示の更新は新しいチャットから有効になる、コードブロックにコメントを混ぜない、プロジェクトファイルの内容を写さない、の3点。

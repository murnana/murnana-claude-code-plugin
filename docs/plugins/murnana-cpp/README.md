# C++

C++(プログラムを書くための言語のひとつ)で書いたプログラムに、読みやすく役に立つ説明書き(コメント)を Claude に書いてもらうためのプラグインです。

> 開発中です。実際のプロジェクトで最後まで通して使うテストはこれからです。

## こんなときに使います

- 自分の書いた C++ のプログラムに、説明書き(コメント)を付けたい
- ほかの人が使う部品に、使い方の説明(Doxygen という道具で読める決まった形の説明)を付けたい
- いまある説明書きが、本当に必要なものか見直したい

## できること

| やりたいこと | 使う機能 | 説明 |
|---|---|---|
| 説明書きを書く・見直す | [C++ のコメント作成](comment.md) | 書く内容をふさわしい場所に振り分けて、必要な説明書きだけを書く |

## インストール

```
claude plugin marketplace add murnana/murnana-claude-code-plugin --sparse .claude-plugin
claude plugin install murnana-cpp@murnana-claude-code-plugin
```

インストールしただけでは使えるようになりません。`/plugin` と入力して開く画面で、このプラグインを有効にしてください。

## 先に入れておくもの

- **Doxygen(説明書きから資料を作る道具)**: 書いた使い方の説明が正しい形になっているかを確かめるのに使います。`brew install doxygen`(Mac)や `apt install doxygen`(Linux)で入ります。入っていないときは、Claude が読み直して確かめますが、見落としが増えます。
- **Python 3**: 確かめる作業を動かすのに使います。Mac や Linux には、たいてい最初から入っています。

## あわせて入れると便利なもの

- **clang(C++ のプログラムを機械の言葉に変える道具のひとつ)**: 入っていると、Doxygen では見つからない説明の誤り(値を返さない部品に「返す値」を書いている、など)も確かめます。
- **C++ のプログラムの中を調べる道具(clangd)**: Claude Code から使えるようにすると、Claude がファイルを丸ごと読まずに、部品の一覧や使われている場所を調べられます。

  ```
  claude plugin install clangd-lsp@claude-plugins-official
  ```

  入れなくても動きます。そのときは、文字列で検索して代わりに調べます。クラウド上の Claude Code では、この道具は動きません。

Claude が勝手にこれらの道具を入れることはありません。

## 知っておいてほしいこと

- **Claude のモデルは Sonnet に固定しています。** この機能を使っている間だけ Sonnet で動き、次にあなたが話しかけると元のモデルに戻ります。
- **プログラムそのものは変えません。** 変えるのはコメントと使い方の説明だけです。
- **理由を作り話にはしません。** 「なぜこう書いたのか」が記録からも分からないときは、あなたに質問します。それでも分からないときは、その場所にはコメントを書かず、報告にまとめます。

# Java

Java(プログラミング言語のひとつ)で書いたプログラムに、読みやすく役に立つ説明書き(コメント)を Claude に書いてもらうためのプラグインです。

> 開発中です。実際のプロジェクトで最後まで通して使うテストはこれからです。

## こんなときに使います

- 自分の書いた Java のプログラムに、説明書き(コメント)を付けたい
- ほかの人が使う部品に、使い方の説明(Javadoc という決まった形の説明)を付けたい
- いまある説明書きが、本当に必要なものか見直したい

## できること

| やりたいこと | 使う機能 | 説明 |
|---|---|---|
| 説明書きを書く・見直す | [Java のコメント作成](comment.md) | 書く内容をふさわしい場所に振り分けて、必要な説明書きだけを書く |

## インストール

```
claude plugin marketplace add murnana/murnana-claude-code-plugin --sparse .claude-plugin
claude plugin install murnana-java@murnana-claude-code-plugin
```

## あわせて入れると便利なもの

- **Java の開発道具一式(JDK)**: 入っていると、書いた説明が決まった形に合っているかを、Java に付いている検査の道具で確かめます。入っていなくても動きますが、確かめられる範囲が狭くなります。
- **Java のプログラムの中を調べる道具(Eclipse JDT Language Server)**: Claude Code から使えるようにすると、Claude がファイルを丸ごと読まずに、部品の場所や使われている場所、型を調べられます。そのぶん、読む量が減ります。道具の本体(`jdtls`)を入れたうえで、Claude Code に次のプラグインを入れてください。道具の本体を動かすには、Java 17 以降が必要です。

  ```
  claude plugin install jdtls-lsp@claude-plugins-official
  ```

  入れなくても動きます。そのときは、ファイルを読んだり文字列で検索したりして代わりに調べます。クラウド上の Claude Code では、この道具は動きません。

## 知っておいてほしいこと

- **Claude のモデルは Sonnet に固定しています。** この機能を使っている間だけ Sonnet で動き、次にあなたが話しかけると元のモデルに戻ります。組織の設定で Sonnet が使えないときは、元のモデルのまま動きます。
- **プログラムそのものは変えません。** 変えるのはコメントだけです。作業の前後でプログラムが変わっていないことを、自動で確かめます。
- **理由を作り話にはしません。** 「なぜこう書いたのか」が記録からも分からないときは、あなたに質問します。質問できないときは、報告の最後に質問として書きます。

## 出典

- 説明書きの置き場所の考え方は、和田卓人さん(@t_wada)の「コードには How テストコードには What コミットログには Why コードコメントには Why not を書こう」(https://x.com/t_wada/status/904916106153828352)をもとにしています。
